# 기획안(PRD) — 본노엘 매뉴얼북 · v2

- 가게 / 이름: 본노엘 베이커리 (서울 직영 4곳, 직원 60~70명) / 
- 주제(영역): 교육 — 직원 매뉴얼 온라인 북 + 신입 숙지 체크
- 이 버전의 목표 한 줄: 이름만 고르고 넘어가는 "확인했어요"를 진짜 이해했는지 확인하는 짧은 퀴즈로 보강하고, 사장님·매니저가 진행률 화면을 매번 열어보지 않아도 놓치는 신입이 눈에 띄게 함

## 1. 무엇을 왜 만들고 싶나요?

v1을 9/17부터 만들어 쓰면서 매장(4곳)·포장 비품·홈 화면·브랜드 톤까지 계속 붙여 왔다. 직원 명단은 94명까지 채웠지만 "확인했어요" 실사용은 아직 5건뿐 — 매일 쓰는 단계까지는 못 갔다. 그 사이 두 가지가 계속 마음에 걸렸다: ① 이름만 고르고 누르면 끝이라 진짜 봤는지·이해했는지 알 방법이 약하다(다른 조 사장님의 "빈숲 OS"에서 본 퀴즈 기능을 보고 확신함) ② 신입이 입사 7일이 지나도 필수 매뉴얼을 안 끝냈는지는 관리자 화면을 직접 열어야만 안다. 카톡·문자 자동 알림도 고려했지만, 채널 심사·비용 없이 화면만으로 해결되는 배지가 지금 단계에는 더 맞는다고 판단했다.

## 2. 누가 언제 쓰나요?

- 신입 직원 — 매뉴얼을 다 보고 "확인했어요"를 누르기 전(또는 후, 매뉴얼별 설정에 따라) 짧은 퀴즈를 품
- 사장님 — 매뉴얼 등록·수정 시 AI가 제안한 퀴즈 문제를 검토·승인, 매뉴얼마다 "통과해야 확인 인정" 여부를 켜고 끔. 홈 화면에서 "미확인" 배지를 봄
- 매니저 (매장당 1명) — 자기 매장 화면에서 "미확인" 배지를 봄 (권한 분리 없이 관리자 화면 공용은 v1과 동일)

## 3. 지금은 어떻게 하고 있나요? (v1 기준)

매뉴얼 상세 맨 아래에서 매장 → 이름 선택 → "확인했어요"만 누르면 끝. 실제로 읽었는지, 이해했는지는 확인할 방법이 없다. 입사 7일이 지나도 필수 매뉴얼이 안 끝난 신입이 있는지는 사장님·매니저가 "신입 진행률" 탭을 직접 열어야만 안다.

## 4. 도구를 쓰면 어떤 일이 달라지나요?

사장님이 매뉴얼을 저장하면 AI가 그 내용을 보고 O/X·객관식 문제 1~2개를 제안 → 사장님이 그대로 쓰거나 고쳐서 승인 → 그 매뉴얼은 "퀴즈 있음" 상태가 됨. 매뉴얼마다 "통과해야 확인 인정"을 켜 두면, 직원은 퀴즈를 맞혀야 "확인했어요"가 눌리고(틀리면 다시 도전), 꺼 두면 퀴즈는 참고용으로 풀되 오답률만 관리자에게 보임. 한편 관리자 홈 화면에는 입사 7일이 지났는데 필수 매뉴얼이 남은 신입이 있으면 사장님 홈 + 해당 매장 매니저 화면에 빨간 숫자 배지가 뜨고, 눌러보면 누가 몇 개 남았는지 바로 보인다.

## 5. 이번 버전에서 만들 것

**꼭 할 것**
- 기능 1: **매뉴얼별 이해도 퀴즈** — 매뉴얼 저장(추가·수정) 시 관리자 화면에 "퀴즈 문제 제안 받기" 버튼 → AI가 제목·단계별 설명·태그를 보고 O/X 또는 객관식(보기 3~4개) 1~2문제를 제안 → 사장님이 문제·정답을 고치거나 그대로 승인해야 저장됨(자동 게시 안 함). 매뉴얼 편집 화면에 "통과해야 확인 인정" 켜기/끄기 토글 추가
  - 준비물: 없음 (같은 Supabase에 문제·정답 저장하는 테이블만 추가)
- 기능 2: **관리자 화면 "미확인 알림" 배지** — 직원 등록일 기준 D+7이 지났는데 그 매장 필수 매뉴얼을 다 못 채운 신입이 있으면, 관리자 홈 진입 시(또는 "신입 진행률" 탭 상단) 빨간 숫자 배지로 표시. 사장님은 전체 매장 합계, 매니저는 자기 매장 것만(로그인 분리는 없으니 매장 선택 화면 기준)
  - 준비물: 없음. 외부 발송 없이 화면 계산만

**이번에 하지 않을 것:** 카톡·문자 자동 발송 [나중] · 매장별 매니저 권한 분리 [나중] · 직원 로그인(본인 PIN) [나중] · 로그북 연결 [나중]

## 6. 완성됐다는 걸 어떻게 확인하나요?

- 시연할 예시 입력: "컵홀더 스티커 붙이는 법" 매뉴얼에서 퀴즈 제안 받기 → O/X 문제 1개 승인, "통과해야 확인 인정" 켬. 다른 매뉴얼 "보건증"은 퀴즈 없이 그대로 둠. 신입 "알바 A"를 등록일 8일 전으로 등록해 두고 필수 매뉴얼 일부만 확인한 상태로 만듦
- 기대하는 결과: 알바 A가 "컵홀더 스티커" 매뉴얼을 열면 확인 버튼 대신 퀴즈가 먼저 뜨고, 맞혀야 "확인했어요"가 눌림. 관리자 홈에는 "미확인 1명" 같은 빨간 배지가 뜨고, 눌러 보면 "성수점 알바 A: 필수 3개 중 2개 남음"이 보임
- 잘못 입력했을 때: 퀴즈 정답이 없이 저장하려 하면 저장 버튼 비활성화 · 매뉴얼에 단계 설명이 하나도 없으면 "AI가 제안할 내용이 부족해요"로 안내하고 사장님이 직접 문제를 씀
- 다시 열었을 때 남아 있어야 할 것: 매뉴얼별 퀴즈 문제·정답·통과 여부 설정, 직원별 퀴즈 결과(맞았는지·몇 번 만에), 배지에 쓰이는 D+7 계산은 새로고침해도 그대로

## 7. 다음 버전에서 더할 것

- v2 사용메모를 보고 정함. 후보: 카톡·문자 자동 발송(배지로도 부족하면), 매장별 매니저 권한 분리, 매뉴얼 조회수·검색어 기록

## 8. 절대 자동화하면 안 되는 것

- "확인했어요"는 본인이 직접 누른다 (퀴즈도 본인이 풀어야 함)
- 퀴즈 문제는 AI가 제안만 하고, 사장님이 승인해야 직원에게 보임 — 자동 게시 안 함
- 배지는 화면에 보여주기만 하고, 알림을 자동으로 내보내지 않는다 (v2는 외부 발송 없음)
